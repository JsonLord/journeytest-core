# Service Interfaces and Space Deployment

All interfaces share one TypeScript `JourneyService`. `journeytest serve` exposes
the versioned API directly. `journeytest ui` runs that API on an internal
loopback port and mounts Gradio plus an API proxy in one public FastAPI ASGI app.
`journeytest space` uses the same composition and, when `LAYA_MODE=auto` detects
a Space, starts and prewarms one managed `localdecide` child process.

```bash
journeytest run --url https://example.com --goal "Open pricing" --json
journeytest serve --port 7860
journeytest ui --port 7860
journeytest space --port 7860
journeytest doctor
journeytest info --json
```

The API supports health, readiness, information, asynchronous journey creation,
status, result, events, cancellation, and known-ID artifacts under `/api/v1`.
Artifact IDs are `result`, `screenshot-N`, and optional `trace`; client
filesystem paths are never accepted. With `trace: true` (or CLI `--trace`), agent-browser records a Chrome
DevTools `trace.json`; JourneyResult exposes it as `artifacts.trace`, and the
artifact route serves it under ID `trace`.

The public OpenAPI 3.1 document is generated by the Node adapter at
`/api/v1/openapi.json`. Both direct `serve` Swagger UI and the composed FastAPI
`/docs` use that contract, covering health, readiness, information, journey
creation/status/result/events/cancellation, and artifacts. Request and response
schemas, including JourneyResult v1 and binary artifact responses, are included.

Public journey inputs reject non-HTTP schemes, localhost, numeric loopback,
private IPv4 ranges, link-local ranges, metadata endpoints, and private/link-local
IPv6 literals. Controlled fixture runs may explicitly set
`JOURNEYTEST_ALLOW_PRIVATE_NETWORKS=1`.

Concurrency is bounded by `MAX_CONCURRENT_JOURNEYS` (default 1) and
`MAX_QUEUED_JOURNEYS` (default 10). All runs share the configured SystemOne
backend while retaining separate browser sessions.

The Docker image installs Node, Python, Google Chrome, agent-browser, Gradio,
FastAPI, and the pinned audited localdecide fork. It starts
`node dist/cli.js space --host 0.0.0.0 --port 7860`. Explicit
`LAYA_MODE=remote` bypasses managed localdecide and uses `LAYA_REMOTE_URL`.

The repository README contains Hugging Face Docker Space metadata (`sdk:
docker`, `app_port: 7860`). The image pins the audited localdecide commit and the
default Laya checkpoint revision, installs the CPU-only PyTorch wheel, pins the
Gradio/FastAPI/HTTPX/Uvicorn versions in `python/requirements-space.txt`, and
includes a container health check.
